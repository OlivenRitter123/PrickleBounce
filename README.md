# Prickle Bounce

A small 2D physics game made for the **Real Life Game Jam** on **November 14, 2026**, with the theme **Bounce Back**.

Aim your cannon, bounce your shot off walls and obstacles, and land it in the moving catcher. Finding the right angle is only half the challenge — timing matters too.

**[Play on itch.io](https://olivenritter753.itch.io/prickle-bounce)**

## How to play

- Move the mouse left and right to aim the cannon.
- Press **Space** to shoot.
- Use walls and obstacles to bounce your shot toward the catcher.
- Land a shot in the catcher to complete the level.

Only one ball can be active at a time. Once it falls out of the play area, you can fire again. Shots are limited, so make them count!

## Controls

| Input | Action |
| --- | --- |
| Mouse movement (horizontal) | Aim the cannon |
| Space | Shoot |
| Left mouse button | Select menu buttons |

## Features

- Three levels
- Physics-based shots and bouncing obstacles
- A catcher that moves from side to side
- Limited shots and one active ball at a time
- Autumn-themed pixel art

## Development

Built in **Unity 6 (6000.3.25f1)** using **C#**, Unity's **2D physics**, and the **Input System**.

To open the project:

1. Clone this repository:
   ```bash
   git clone https://github.com/OlivenRitter123/PrickleBounce.git
   ```
2. Add the cloned folder as a project in Unity Hub.
3. Open it with Unity **6000.3.25f1** and let Unity import the assets and packages.
4. Open `Assets/Scenes/Menu.unity` and press **Play**.

The playable levels are in `Assets/Scenes/Level1.unity`, `Level2.unity`, and `Level3.unity`.
